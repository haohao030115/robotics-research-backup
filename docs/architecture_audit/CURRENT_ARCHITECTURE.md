# Current architecture

## Runtime layers

1. **Expert generation.** Kimodo generates G1 motion through its model and MuJoCo exporter; the T7 adapter resamples to 50 Hz, converts joint order and quaternions, and writes a body/root intermediate (`kimodo_to_t7_reference.py:38-99,163-244`). ARDY generates 25 FPS segments with native history/overlap blending, converts to MuJoCo qpos, then adapts wrists through per-frame IK (`research/ardy/generate_segmented.py:95-150`; `adapt_ardy.py:40-113`). Local rule references are generated by `dl-group2/scripts/generate_rule_reference.py`. Kimodo/ARDY/rule producers converge on local reference artifacts, but they do not share one typed producer interface.
2. **Reference adaptation.** `adapt_model_reference.py` mirrors arm names when needed, applies a smooth Cartesian displacement, solves actual-model IK, preserves the reset pose and writes a candidate (`dl-group2/scripts/adapt_model_reference.py`). ARDY uses a separate clearance, wrist orientation, calibration and compensation path. This is application-specific adaptation, not SONIC code.
3. **SONIC whole-body control.** `run_sonic_grasp.py:156-260` creates MuJoCo state, initializes the source frame, uses startup WBC only before playback, receives 29 body commands from DDS/native SONIC, applies body torques, and independently applies 14 hand joints through `HandTrajectoryController` (Kp 12, Kd .3). Frozen native SONIC has planner/control/command-writer periods of 50/50/500 Hz and performs release ONNX encode/decode (`g1_deploy_onnx_ref.cpp:176-188,2627-2635,2702-2720`).
4. **Canonical factory.** `canonical_va.pipeline.run` validates the reference, checks source hashes and rendering, runs native replay or revalidates an immutable recorded replay, materializes ID-linked observations/references/encoder/decoder/physics/RGB traces, performs forensic checks, and exports only an `expert_valid` episode (`pipeline.py:57-145`; `native_truth.py:31-101`). The old synchronous implementation is archived as text and is not executable (`canonical_va/replay.py:1-5`).
5. **Dataset.** `canonical_va.compiler.plan_samples` selects active observations, three-state history and future offsets `[2..6]`, joins by explicit IDs and exports post-FSQ 64D tokens plus 14D absolute hand references (`compiler.py:9-70`). `va_training.v4.dataset.CanonicalV4` revalidates one complete canonical episode, checks 50 Hz, wxyz, contiguous IDs and complete 10/50-step horizons (`v4/dataset.py:43-125`). `grasp_pipeline.dataset` serializes multiple canonical episodes with explicit episode-disjoint splits (`dataset.py:57-90`).
6. **VA training.** V4 accepts RGB `[B,3,128,128]`, body state 68D and hand state 28D. It predicts 10 body tokens ×64, 50 hand references ×14, phase logits and closure progress (`v4/model.py:24-58`). Training uses Smooth L1 token, MSE hand, phase cross entropy and progress MSE (`v4/losses.py:4-9`), MUSA in `v4/training.py:37-79`, and provenance hashes in checkpoints. Earlier baseline/flow, V2 and V3 remain separate model families; V4.1, oracle and BCZ hand are descendants/ablations.
7. **Closed loop.** The worker renders 320×240 RGB on the validated MTT renderer, resizes to 128×128, runs MUSA inference, and returns plans. `PlanBuffer` inserts 10-token/50-hand plans at authored absolute ticks, rejects gaps and uncovered ticks, and records deadline/fallback counters (`v4/runtime.py:9-58`; `v4/rollout.py:23-56,121-207`). NativeTokenSonic owns decoder history and DDS transport; VA supplies external tokens. BCZ adds a learned closure-intent head and `OneShotHand` execution policy (`v4_0_bcz_hand/model.py:1-13`; `v4_0_bcz_hand/train_full.py:7-37`; `v4/one_shot_rollout.py:117-134`).

## Execution contexts

| Context | Entry points | Transport/rendering | Output |
|---|---|---|---|
| Offline expert generation | Kimodo `generate.py`, ARDY `run_pipeline.py`, local rule scripts | MUSA model; no DDS | Motion/reference candidate |
| Native canonical production | `python -m canonical_va.pipeline` or `canonical_va.batch` | Isolated DDS, original native controller, MuJoCo, validated EGL | Full canonical episode and audit |
| Dataset build | `grasp_pipeline.cli dataset build` / canonical compiler | Offline tensor/file joins | `samples.npz`, mappings, manifest |
| VA training | `va_training.v4.training`, `v4.train_merged`, BCZ `train_full.py` | MUSA; no DDS | checkpoint and metrics |
| Offline evaluation | `v4.evaluation`, `grasp_pipeline.evaluation` | CPU inspection is allowed; no native control | metrics and plots |
| Closed-loop inference | `run_token_v4_closed_loop.py`, `v4.rollout`, `v4_0_bcz_hand` rollout | Isolated DDS, MTT EGL, native SONIC | runtime report, scheduler trace, physics/RGB |
| Legacy/experimental | V2/V3/flow/oracle/Qwen/ARDY staged tools | Varies; many snapshots | Experiment-specific artifacts |

## Frozen interfaces

The protected interfaces are source/reference hashes, 29 body +14 hand joint order, wxyz quaternions, 50 Hz reference/control semantics, 200 Hz physics, 500 Hz native command publication, release ONNX dimensions, FSQ 32-level projection, explicit ID joins, independent hand PD, native DDS and physical grasp criteria (0.10 m lift, 2 s continuous hold with valid opposing contacts and no cube/table contact). These are verified contracts, not refactoring targets.
